# 贪吃蛇游戏 - 需求文档

## 当前实现对齐说明（v1.2.1）

- Hard 模式默认速度为 `120ms`。
- 技能输入支持双通道：加速 `Q/鼠标右键`，金身 `F/鼠标左键`。
- 持久化文件写入可写用户目录（`%APPDATA%/SnakeGame` 或 `user.home/.snakegame`）。
- 设置页支持滚动扩展，且从游戏页进入时自动匹配当前模式。

## 项目概述

开发一个基于 Java Swing 的贪吃蛇游戏，包含多种游戏模式和排行榜功能。

## 功能需求

### 1. 核心游戏功能

#### 1.1 蛇的移动和控制
- **需求描述**：玩家可以通过键盘控制蛇的移动方向
- **功能要求**：
  - 支持方向键（↑↓←→）控制
  - 支持 WASD 键控制
  - 防止蛇反向移动（如向右时不能向左）
  - 蛇的移动流畅，无卡顿
- **优先级**：高
- **验收标准**：按键响应及时，方向控制准确

#### 1.2 食物系统
- **需求描述**：游戏区域内随机生成食物，蛇吃到食物后增长
- **功能要求**：
  - 食物随机生成，不与蛇身重叠
  - 蛇头与食物重合时，蛇长度+1
  - 食物被吃后立即在新位置重新生成
  - 每吃一个食物得10分
- **优先级**：高
- **验收标准**：食物生成合理，碰撞检测准确

#### 1.3 碰撞检测
- **需求描述**：检测蛇是否撞到墙壁或自己的身体
- **功能要求**：
  - 蛇头撞到游戏区域边界，游戏结束
  - 蛇头撞到自己的身体，游戏结束
  - 碰撞后显示游戏结束提示
- **优先级**：高
- **验收标准**：碰撞检测准确，游戏结束判断正确

#### 1.4 游戏循环
- **需求描述**：游戏通过定时器循环更新状态
- **功能要求**：
  - 使用 Timer 实现游戏循环
  - 定时器触发时更新蛇的位置
  - 每次更新后重绘界面
  - 支持游戏暂停/继续功能
- **优先级**：高
- **验收标准**：游戏循环稳定，帧率合理

---

### 2. 游戏模式功能

#### 2.1 Normal 模式（普通模式）
- **需求描述**：标准的贪吃蛇游戏体验
- **功能要求**：
  - 初始速度：250ms（每秒约4帧）
  - 速度恒定，不随时间变化
  - 适合新手玩家
  - 独立的排行榜（normalRank）
- **优先级**：中
- **验收标准**：速度适中，游戏体验流畅

#### 2.2 Hard 模式（困难模式）
- **需求描述**：更快的游戏速度，考验玩家反应
- **功能要求**：
  - 初始速度：120ms（每秒约8帧）
  - 速度恒定，不随时间变化
  - 适合有经验的玩家
  - 独立的排行榜（hardRank）
- **优先级**：中
- **验收标准**：速度较快，具有挑战性

#### 2.3 Crazy 模式（疯狂模式）
- **需求描述**：速度逐渐加快的挑战模式
- **功能要求**：
  - 初始速度：250ms
  - 每次吃食物后速度加快10ms
  - 最小速度限制：30ms
  - 适合高手玩家
  - 独立的排行榜（crazyRank）
- **优先级**：中
- **验收标准**：速度递增合理，不会过快导致无法玩

### 3. 用户界面功能

#### 3.1 主菜单界面
- **需求描述**：游戏启动后显示主菜单
- **功能要求**：
  - 显示三个模式选择按钮（Normal、Hard、Crazy）
  - 显示排行榜入口按钮
  - 按钮样式统一，位置合理
  - 背景色协调美观
- **优先级**：高
- **验收标准**：界面清晰，按钮功能正常

#### 3.2 游戏界面
- **需求描述**：显示游戏主要内容和状态
- **功能要求**：
  - 显示游戏区域（绿色背景，黑色游戏区）
  - 显示网格线帮助定位
  - 显示当前分数、蛇长度、游戏速度
  - 显示游戏状态提示（开始、暂停、结束）
  - 游戏结束后显示操作按钮
- **优先级**：高
- **验收标准**：信息显示完整，布局合理

#### 3.3 排行榜界面
- **需求描述**：显示各模式的最高分记录
- **功能要求**：
  - 显示当前模式的排行榜（前10名）
  - 显示排名、模式名称、分数
  - 支持切换不同模式的排行榜
  - 提供返回菜单按钮
- **优先级**：中
- **验收标准**：排行榜显示正确，切换流畅

#### 3.4 按钮功能
- **需求描述**：提供游戏操作和导航按钮
- **功能要求**：
  - 游戏界面的"返回菜单"按钮
  - 游戏界面的"查看排名"按钮
  - 排行榜界面的"返回菜单"按钮
  - 按钮点击后正确跳转页面
- **优先级**：高
- **验收标准**：按钮响应及时，页面切换正确

---

### 4. 数据持久化功能

#### 4.1 排行榜数据保存
- **需求描述**：游戏结束后自动保存最高分
- **功能要求**：
  - 使用 Properties 类存储数据
  - 每个模式独立保存前10名
  - 数据保存到用户可写目录中的 rankings.dat 文件
  - 路径由 `AppPaths` 统一管理（默认 `%APPDATA%/SnakeGame`）
  - 文件格式为 key=value 形式
- **优先级**：高
- **验收标准**：数据保存成功，文件格式正确

#### 4.2 排行榜数据加载
- **需求描述**：程序启动时自动加载排行榜数据
- **功能要求**：
  - 从用户可写目录中的 rankings.dat 文件读取数据
  - 文件不存在时使用默认数据
  - 数据加载失败时有错误提示
  - 静态代码块自动加载
- **优先级**：高
- **验收标准**：数据加载成功，默认值合理

#### 4.3 数据更新机制
- **需求描述**：游戏结束后更新排行榜
- **功能要求**：
  - 分数插入到正确的位置（降序排列）
  - 只保留前10名最高分
  - 避免重复更新同一分数
  - 更新后立即保存到文件
- **优先级**：高
- **验收标准**：排名更新准确，数据不丢失

---

### 5. 页面管理功能

#### 5.1 页面切换
- **需求描述**：在不同界面之间切换
- **功能要求**：
  - 使用 CardLayout 实现页面切换
  - 主菜单 → 游戏界面
  - 游戏界面 → 主菜单
  - 游戏界面 → 排行榜界面
  - 排行榜界面 → 主菜单
- **优先级**：高
- **验收标准**：切换流畅，状态正确

#### 5.2 菜单状态管理
- **需求描述**：管理菜单的不同状态
- **功能要求**：
  - 普通模式：模式按钮开始游戏
  - 排行榜模式：模式按钮查看排行榜
  - 点击排行榜按钮后隐藏排行榜按钮
  - 返回菜单时重置菜单状态
- **优先级**：中
- **验收标准**：状态切换正确，按钮显示/隐藏正确

#### 5.3 游戏状态管理
- **需求描述**：管理游戏的不同状态
- **功能要求**：
  - 未开始状态：显示开始提示，显示返回菜单按钮
  - 进行中状态：隐藏所有按钮
  - 结束状态：显示结束信息，显示两个按钮
  - 暂停功能：空格键暂停/继续
- **优先级**：高
- **验收标准**：状态转换正确，提示信息准确

### 6. 性能要求

#### 6.1 响应性能
- **需求描述**：用户操作及时响应
- **功能要求**：
  - 键盘按键响应延迟 < 50ms
  - 按钮点击响应及时
  - 页面切换无卡顿
  - 游戏循环稳定
- **优先级**：中
- **验收标准**：操作流畅，无明显延迟

#### 6.2 内存使用
- **需求描述**：游戏运行时内存占用合理
- **功能要求**：
  - 蛇身数组最大长度200
  - 图片资源合理加载
  - 避免内存泄漏
  - 及时释放资源
- **优先级**：中
- **验收标准**：内存占用 < 100MB

#### 6.3 文件操作
- **需求描述**：数据文件操作高效可靠
- **功能要求**：
  - 文件读写使用缓冲流
  - 异常处理完善
  - 文件操作不影响游戏性能
  - 支持文件不存在的情况
- **优先级**：中
- **验收标准**：文件操作稳定，无数据丢失
