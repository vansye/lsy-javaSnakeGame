# 数据结构和存储说明

## 一、核心数据类

### 1. Snake类（蛇）

**数据结构：**
```java
public static int[] skx = new int[200];  // 蛇身X坐标数组
public static int[] sky = new int[200];  // 蛇身Y坐标数组
private static int length = 3;           // 蛇身长度
private static String direction = "R";   // 蛇头方向
```

**存储说明：**
- `skx[]` 和 `sky[]` 数组长度均为200，用于存储蛇身所有节点的坐标
- 索引0表示蛇头，索引1~length-1表示蛇身
- 坐标单位为像素，每个节点间隔25像素
- 方向使用字符串："R"(右)、"L"(左)、"U"(上)、"D"(下)

---

### 2. Food类（食物）

**数据结构：**
```java
private static int fx = 600;           // 食物X坐标
private static int fy = 300;           // 食物Y坐标
private static int speedChangeRate = 5; // 速度变化率
```

**存储说明：**
- `fx` 和 `fy` 存储当前食物位置坐标
- 食物位置范围：X轴0-750，Y轴50-550（步长25）
- `speedChangeRate` 控制吃完食物后速度增加量

---

### 3. GamePanel类（游戏面板）

**数据结构：**
```java
private static boolean isStart = false;    // 游戏是否开始
private static boolean isDead = false;      // 游戏是否结束
private static int score = 0;              // 当前得分
private static int speed = 250;            // 游戏速度(毫秒)
private static int time = 180;             // 剩余时间(秒)
private static boolean scoreUpdate = false;// 分数是否更新
private static String gameMode = "normal"; // 游戏模式
private Timer timer;                        // 游戏主定时器
```

**存储说明：**
- `isStart` 控制游戏开始/暂停状态
- `isDead` 控制游戏结束状态
- `score` 初始值为0，每次吃食物增加10分
- `speed` 控制游戏刷新频率，值越小速度越快（范围30-250毫秒）
- `time` 倒计时用，不同模式初始值不同
- `gameMode` 存储当前游戏模式："normal"、"hard"、"crazy"

---

### 4. RankPanel类（排行榜）

**数据结构：**
```java
private static int[] normalRank = new int[10];    // 普通模式排行榜
private static int[] hardRank = new int[10];       // 困难模式排行榜
private static int[] crazyRank = new int[10];      // 疯狂模式排行榜
private static LocalDateTime[] normalTime = new LocalDateTime[10];  // 普通模式时间
private static LocalDateTime[] hardTime = new LocalDateTime[10];    // 困难模式时间
private static LocalDateTime[] crazyTime = new LocalDateTime[10];   // 疯狂模式时间
```

**存储说明：**
- 三个数组分别存储三种游戏模式的排行榜分数
- 每个排行榜最多存储10个分数，按分数降序排列
- 时间数组存储对应分数的记录时间

---

## 五、核心算法

### 1. 蛇的移动算法

```java
// 蛇身移动：从后向前移动
for (int i = length - 1; i > 0; i--) {
    skx[i] = skx[i - 1];
    sky[i] = sky[i - 1];
}
// 蛇头移动
skx[0] += 25;  // 向当前方向移动一格
```

### 2. 碰撞检测算法

```java
// 食物碰撞
if (蛇头坐标 == 食物坐标) {
    吃掉食物();
    蛇身长度++;
    分数+=10;
    生成新食物();
}

// 自身碰撞
for (int i = 1; i < length; i++) {
    if (蛇头坐标 == 蛇身节点[i]坐标) {
        游戏结束();
    }
}

// 边界碰撞
if (蛇头坐标超出游戏区域) {
    游戏结束();
}
```
