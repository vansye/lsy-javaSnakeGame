# 贪吃蛇游戏

一个基于 Java Swing 开发的经典贪吃蛇游戏，包含多种游戏模式和排行榜功能。

---

## 📖 项目简介

这是一个功能完整的贪吃蛇游戏，提供三种不同难度的游戏模式，支持排行榜数据持久化，界面简洁美观，操作流畅。你需要控制一条蛇在游戏区域内移动，吃掉食物来增长身体并获得分数。但要小心！不要撞到墙壁或自己的身体，否则游戏就结束了。

---

## ✨ 功能特性

### 🎮 游戏模式
- **Normal 模式**：标准速度，适合新手玩家
- **Hard 模式**：快速移动，考验反应能力
- **Crazy 模式**：速度递增，极具挑战性

### 🏆 排行榜系统
- 每种模式独立排行榜（前10名）
- 数据持久化保存，关闭游戏不丢失
- 显示游戏结束时间
- 自动更新最高分记录

### 🎨 用户界面
- 简洁直观的主菜单
- 清晰的游戏信息显示
- 实时分数、长度、速度显示
- 流畅的页面切换

### 🎯 游戏功能
- 键盘方向控制（WASD 或方向键）
- 游戏暂停/继续功能
- 游戏结束后重新开始
- 返回菜单和查看排名按钮
- **多食物系统**：场上同时存在 5 个食物，吃完自动补位
- **技能系统**：加速冲刺与金身护体

## 🚀 快速开始

### 环境要求
- **Java 版本**：Java 8 或更高
- **操作系统**：Windows / macOS / Linux
- **内存**：至少 256MB RAM
- **屏幕分辨率**：800x600 或更高

### 运行游戏

#### 方式1：使用 IDE 运行
1. 使用 IntelliJ IDEA 或 Eclipse 打开项目
2. 找到 `Main.java` 文件
3. 右键点击 → Run 'Main.main()'

#### 方式2：命令行运行
```bash
# 编译项目
javac -d bin src/com/SnakeGame/game/*.java

# 运行游戏
java -cp bin com.SnakeGame.game.Main
```

#### 方式3：运行 JAR 文件
```bash
java -jar SnakeGame.jar
```

### 数据文件位置（重要）
- 排行榜和用户配置会写入可写目录，而不是 JAR 所在目录。
- 默认路径：
  - Windows：`%APPDATA%/SnakeGame`
  - 其他系统回退：`$HOME/.snakegame`
- 可选：通过 JVM 参数覆盖数据目录

```bash
java -Dsnake.data.dir="D:/SnakeGameData" -jar SnakeGame.jar
```

## 🎮 游戏指南

### 游戏模式详解

#### 🎮 Normal 模式（普通模式）
- **适合人群**：新手玩家
- **游戏特点**：标准速度，节奏适中
- **初始速度**：250ms（每秒约4帧）
- **难度**：⭐⭐

#### 🎮 Hard 模式（困难模式）
- **适合人群**：有经验的玩家
- **游戏特点**：快速移动，考验反应能力
- **初始速度**：120ms（每秒约8帧）
- **难度**：⭐⭐⭐⭐

#### 🎮 Crazy 模式（疯狂模式）
- **适合人群**：高手玩家
- **游戏特点**：速度逐渐加快，极具挑战性
- **初始速度**：250ms，每次吃食物加快10ms
- **难度**：⭐⭐⭐⭐⭐⭐

### 操作说明

#### 键盘控制
- **↑ / W**：向上移动
- **↓ / S**：向下移动
- **← / A**：向左移动
- **→ / D**：向右移动
- **空格键**：
  - 游戏未开始时：开始游戏
  - 游戏进行中：暂停游戏
  - 游戏结束时：重新开始游戏
- **Q（按住）或鼠标右键（按住）**：加速（最多持续5秒，冷却3秒）
- **F（按住）或鼠标左键（按住）**：金身（最多持续2秒，冷却5秒，期间撞障碍不死亡）

#### 鼠标操作
- 点击按钮进行页面切换和功能选择
- 游戏中按住鼠标右键：加速
- 游戏中按住鼠标左键：金身

### 游戏规则

1. **目标**：吃掉食物获得分数，每吃一个食物得10分
2. **增长**：每次吃食物，蛇的长度增加1
3. **速度**：
   - Normal 模式：速度恒定（250ms）
   - Hard 模式：速度恒定（120ms）
   - Crazy 模式：每次吃食物后速度加快10ms（最小30ms）
4. **游戏结束**：蛇头撞到墙壁或自己的身体
5. **排行榜**：游戏结束后自动更新排行榜

### 游戏技巧

#### 🎯 新手技巧
1. **从慢开始**：先尝试 Normal 模式，熟悉操作
2. **不要贪心**：不要为了吃食物而冒险
3. **规划路线**：提前规划蛇的移动路线
4. **保持冷静**：不要慌张，按部就班地操作

#### 🎯 进阶技巧
1. **利用空间**：在游戏区域内充分利用空间
2. **控制节奏**：合理使用暂停功能（空格键）
3. **观察模式**：不同模式需要不同的策略
4. **练习反应**：Hard 模式可以训练反应速度

#### 🎯 高手技巧
1. **Crazy 模式**：在速度加快前尽可能多吃食物
2. **极限挑战**：尝试打破自己的最高分记录
3. **速度适应**：适应逐渐加快的游戏节奏
4. **完美操作**：追求零失误的完美游戏

## ❓ 常见问题

### Q1: 如何开始游戏？
**A**: 在主菜单中选择一个模式（Normal/Hard/Crazy），进入游戏界面后按空格键开始。

### Q2: 如何暂停游戏？
**A**: 在游戏进行中按空格键可以暂停游戏，再次按空格键继续。

### Q3: 排行榜数据会保存吗？
**A**: 是的！游戏结束后会自动保存，默认保存到 `%APPDATA%/SnakeGame/rankings.dat`（Windows），关闭游戏后数据不会丢失。

### Q4: 如何查看排行榜？
**A**: 在主菜单点击"Ranking List"按钮，然后选择要查看的模式（Normal/Hard/Crazy）。

### Q5: 游戏结束后如何重新开始？
**A**: 游戏结束后按空格键可以重新开始当前模式，或者点击"返回菜单"按钮选择其他模式。

### Q6: Crazy 模式的速度会一直加快吗？
**A**: 不会的。速度会加快到最小30ms后不再变化，保证游戏可玩性。

### Q7: 可以自定义游戏设置吗？
**A**: 可以。在设置页可按模式分别配置初始速度、加速变化值、限时秒数、障碍数量，以及 custom 棋盘/网格/障碍颜色。配置会保存到 `%APPDATA%/SnakeGame/user-config.properties`（Windows），下次启动自动加载。
